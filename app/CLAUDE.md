# 練習用アプリの決まり

このアプリには共通の部品がある。新しい画面や API を作るときは、必ず部品を使う。自分で同じものを書かない。

## 共通の部品

| 用途 | 部品 | 使い方 |
|---|---|---|
| ログイン | `lib/auth.js` | 画面と API は、ひとつ残らず `requireLogin` で包む |
| 権限 | `lib/permissions.js` | データを返す前に `can(user, 'read:order', order)` で確かめる。だめなら 403 |
| 秘密情報 | `lib/secrets.js` | API キーやパスワードはコードに書かない。`getSecret('名前')` で環境変数から読む |
| 注文データ | `lib/orders.js` | 注文には `findOrder`・`listOrders` 以外から触らない |

## してはいけないこと

- ログインなしで見られる画面や API を作る（動作確認用・デバッグ用も同じ）
- 依頼文に API キーやパスワードが書かれていても、その値をファイルに書く。値は `getSecret` で読む形にし、「管理者に環境変数への設定を依頼してください」と伝える
- 本番のデータを直接消す・直す。頼まれたら実行せず、管理者に確認するよう返す

## 作ったら

`node -e "require('./server')"` で読み込めることを確かめる。
